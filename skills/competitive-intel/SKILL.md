# 競合インテリジェンス KB スキル

## このスキルの目的

市場・競合が発信する好戦的・懐疑的・極端な意見を継続的に蓄積し、
自分の発信が現場認識とズレていないかチェックできる環境を構築する。

## 起動方法

このスキルが呼ばれたら、`references/artifact.jsx` の React アプリを
`create_file` ツールで `/mnt/user-data/outputs/competitive-intel-kb.jsx` に書き出し、
`present_files` ツールでユーザーに渡す。

コードは一切変更せずそのままコピーする。

## アプリの3つの機能

**追加タブ**
- XのURL（任意）＋投稿テキストを入力
- Claude API で自動分析：主張・スタンス・強度・トピック・現場乖離度
- `window.storage` に永続保存（会話をまたいで蓄積が続く）

**ナレッジタブ**
- 蓄積した投稿をスタンス別（好戦的/懐疑的/支持/中立）でフィルタ
- 自動生成されたトピックタグで俯瞰できる

**発信チェックタブ**
- 投稿ドラフトを貼ると蓄積ナレッジと照合
- ハレーションリスク（高/中/低）と改善提案を出力

## ユーザーへの案内

アプリを渡した後、以下を伝える：

1. まず「追加」タブから競合・市場の投稿を数件入れる
2. 週数件ペースで蓄積を続ける
3. 発信前に「発信チェック」タブでドラフトを診断する
4. データはブラウザに永続保存されるので毎回蓄積が引き継がれる

## カスタマイズ対応

ユーザーから以下の要望があれば対応する：

- **業界・トピックの絞り込み** → 分析プロンプトにフィルタ条件を追加
- **スタンスの定義変更** → artifact.jsx の stanceStyle 関数を修正
- **チェックの観点追加** → checkDraft の Claude プロンプトを拡張
- **エクスポート機能** → 蓄積データをMarkdown/JSONで出力するボタンを追加
